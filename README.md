# sql_dataset1
Cleaned and analyzed Superstore sales data using Python and SQLite.
Calculated total sales by region and category using aggregation in pandas and SQL.
Performed SQL queries with SELECT, WHERE, ORDER BY, GROUP BY, and JOINS.
Used subqueries, aggregate functions (SUM, AVG), and views for insights.
Optimized query performance using indexes.
Tools used: Python, Pandas, SQLite, SQLAlchemy.
